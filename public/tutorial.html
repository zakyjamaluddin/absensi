1

Instalasi Berkas & Domain di Hosting

Mempersiapkan subdomain dan mengekstrak berkas aplikasi di File Manager cPanel / DirectAdmin

1.1

Buat Subdomain Khusus

Masuk ke panel hosting (cPanel), buka menu Domains / Subdomains, lalu tambahkan domain berikut:

absensi.maisba.sch.id

PRAKTIS: Sudah Dilengkapi .htaccess Otomatis

Klien tidak perlu repot mengubah Document Root ke /public! Cukup ekstrak di root subdomain (contoh: /public_html/absensi), berkas .htaccess bawaan kami akan langsung mengarahkan seluruh pengunjung ke sistem secara otomatis dan aman (file .env otomatis terproteksi dari akses luar).

1.2

Upload & Ekstrak .ZIP

Buka File Manager hosting, masuk ke direktori tempat subdomain berada, lalu upload file zip yang telah Anda unduh dari Google Drive.

  • Klik kanan file zip → pilih Extract.
  • Pastikan seluruh folder seperti app, bootstrap, public berada di root subdomain.
  • Setelah selesai ekstrak, file .zip boleh dihapus untuk menghemat ruang disk hosting.
1.3

Izin Folder (Permissions)

Pastikan sistem web server dapat menulis log dan cache di folder storage:

storage/ → Permission: 775 / 755 Writable
bootstrap/cache/ → 775 / 755 Writable

Gunakan PHP versi 8.2 atau 8.3 di cPanel (MultiPHP Manager) dengan ekstensi pdo, intl, bcmath, fileinfo, gd aktif.

2

Setup Database MySQL & Sinkronisasi .env

Membuat basis data di hosting, mengimpor starter SQL, dan menghubungkan kredensial di file konfigurasi

2.1 Pembuatan Database & Import SQL

phpMyAdmin

1. Buat Database & Pengguna: Masuk ke cPanel → MySQL® Databases. Buat nama basis data, nama pengguna (user), dan kata sandi baru. Penamaan dan kata sandi bebas sesuai keinginan Anda.

2. Hubungkan User ke Database: Pada bagian Add User to Database, pilih user dan database yang dibuat tadi, lalu klik Add dan centang opsi ALL PRIVILEGES.

3. Import File SQL:

  • Buka menu phpMyAdmin dari cPanel.
  • Pilih database yang baru saja Anda buat di panel sebelah kiri.
  • Buka tab Import di bagian atas.
  • Pilih file SQL yang sudah diunduh (Unduh dari Google Drive di sini).
  • Klik tombol Go / Kirim di bagian bawah.

Kelebihan Starter SQL Ini: Klien tidak perlu menjalankan php artisan db:seed di hosting. File SQL ini sudah memuat skema tabel, 8 peran lengkap, 50 hari libur nasional 2026–2027, serta akun default langsung aktif!

2.2 Penyesuaian File .env

Konfigurasi

Di cPanel File Manager, aktifkan opsi Show Hidden Files (dotfiles). Buka dan edit file .env di root aplikasi, lalu sesuaikan bagian berikut:

.env configuration snippet
APP_NAME="Absaka"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://absensi.maisba.sch.id
# Sesuaikan dengan Database yang dibuat di cPanel:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nama_database_anda
DB_USERNAME=nama_user_db_anda
DB_PASSWORD=kata_sandi_db_anda

Simpan perubahan file .env. Setelah tersimpan, aplikasi telah terhubung secara sempurna dan siap untuk diakses!

Registrasi Mandiri Guru & Siswa via "Sign in with Google"

Admin tidak perlu membuat akun pengguna satu per satu untuk ratusan siswa dan dewan guru!

1. Klik Masuk Google

Guru atau siswa membuka halaman login dan mengklik tombol Sign in with Google menggunakan akun Gmail mereka.

2. Verifikasi NIP / NIS

Saat pertama kali mendaftar, sistem meminta nomor identitas. Jika NIP terdeteksi, akun otomatis diberi peran Guru; jika NIS terdeteksi, otomatis diberi peran Siswa.

3. Sekali Klik Seterusnya

Untuk login di kemudian hari, guru & siswa cukup mengklik tombol Google satu kali tanpa perlu memasukkan NIP/NIS lagi.

Panduan Cepat Operasional (Quickstart)

Langkah sistematis penyiapan data awal sistem Presensi dan Perpustakaan agar siap dipakai

Prasyarat Awal Sebelum Memulai:

✓ Login Akun Tepat

Pastikan Anda telah masuk sebagai Super Administrator atau Admin Absensi untuk mengatur modul ini.

✓ Pasang PWA di Perangkat

Klik tombol "Install Aplikasi" di bagian bawah bilah samping (sidebar) pada laptop/HP agar berjalan seperti aplikasi native.

✓ Aktifkan Notifikasi Cerdas

Klik tombol "Aktifkan Notifikasi" di sidebar dan izinkan peramban (Allow Notification) untuk menerima alarm presensi H-5 menit.

A Alur Penyiapan Sistem Presensi & WhatsApp

Modul Utama
Langkah 1 Master Data

Input Data Guru

Buka menu Data Guru → Tambah Guru. Masukkan NIP, Nama Lengkap, dan Nomor WhatsApp aktif (format 08xxx atau 62xxx) agar guru menerima rekap absensi.

Langkah 2 Master Data

Input Data Kelas & Wali Kelas

Buka menu Data Kelas → Tambah Kelas. Beri nama kelas (contoh: X TKJ 1, XI RPL 2) dan pilih guru pembina sebagai Wali Kelas yang berhak mengekspor laporan bulanan.

Langkah 3 Master Siswa

Input Siswa & Kartu RFID

Buka menu Data Siswa → Tambah Siswa. Masukkan NIS, Nama, Kelas, Nomor WA Wali Murid, dan tap kartu RFID pada kolom kartu (atau isi kode unik kartu).

Langkah 4 Identitas Kartu

Unduh & Cetak QR Code Siswa

Pada tabel Siswa, klik tombol Unduh QR Code. Barcode QR ini dapat dicetak pada kartu identitas pelajar sebagai alternatif scan kamera apabila belum memakai kartu RFID tap.

Langkah 5 Integrasi WA

Integrasi API Sidobe WhatsApp

Buka menu Integrasi WA → masukkan Token API Sidobe. Pilih metode proses alpa (Otomatis atau Manual) dan aktifkan notifikasi kehadiran ke orang tua/wali murid.

Langkah 6 Aturan Jam

Atur Jam Absensi Siswa & Guru

Buka menu Pengaturan Jam. Tentukan:
• Mulai Masuk (contoh: 06:00)
• Batas Tepat Waktu (contoh: 07:00)
• Batas Akhir Masuk & Jam Mulai Pulang.

Langkah 7 Jadwal Harian

Atur Jadwal Guru Piket

Buka menu Jadwal Guru Piket. Masukkan guru piket harian (Senin s/d Sabtu). Pada hari bertugas, guru piket otomatis menerima notifikasi push permohonan izin baru dan mendapatkan akses ke menu Pengajuan Izin Masuk untuk menyetujui (approve) atau menolak izin/sakit siswa & guru (guru yang tidak piket hanya memiliki menu mandiri Ajukan Izin).

Langkah 8 Kalender SKB

Sinkronkan Libur Nasional

Buka menu Hari Libur → klik tombol "Sinkronkan Libur Nasional" untuk memperbarui kalender libur otomatis (sistem otomatis mengirim pengingat notifikasi H-3 sebelum libur).

Langkah 9 Siap Tap!

Jalankan Scanner Absensi

Buka menu Scanner Absensi di komputer pos gerbang sekolah. Hubungkan alat scan RFID USB atau gunakan webcam/kamera HP. Siswa dan guru langsung tap untuk presensi real-time!

B Alur Penyiapan Sistem Perpustakaan Digital & Literasi

Modul Literasi
Langkah 1 Aturan Sirkulasi

Atur Pengaturan Perpustakaan

Buka menu Pengaturan Perpustakaan. Atur durasi pinjam default (misal: 7 hari), serta poin reward untuk kunjungan membaca dan poin peminjaman buku.

Langkah 2 Katalog Pustaka

Input Master Data Buku

Buka menu Data Buku → Tambah Buku. Masukkan Judul Buku, Penulis, Penerbit, Nomor ISBN / Kode Barcode, Kategori Rak, dan Jumlah Eksemplar (Stok Buku).

Langkah 3 Meja Pengunjung

Siapkan Scanner Perpustakaan

Buka menu Scanner Perpustakaan di meja sirkulasi. Siswa yang masuk cukup men-tap kartu RFID / memindai QR code mereka; sistem mencatat riwayat kunjungan dan memberi poin literasi secara otomatis!

Langkah 4 Sirkulasi

Peminjaman & Pengembalian

Buka menu Peminjaman Buku untuk mencatat buku yang dipinjam siswa. Sistem menghitung tanggal jatuh tempo dan mengirim notifikasi saat buku harus dikembalikan.

Langkah 5 Gamifikasi & Apresiasi

Pantau Rating Minat Literasi

Buka menu Rating Minat Literasi untuk melihat visualisasi podium bertingkat 3 siswa teratas dengan poin literasi tertinggi di sekolah. Gunakan data ini untuk memberi piagam/apresiasi berkala pada siswa berprestasi.

Solusi Masalah: Foto Siswa Tidak Tampil (Error 403 Forbidden di Hosting)

Panduan perbaikan cepat jika foto siswa atau gambar profil mengalami kendala izin akses di shared hosting

Penyebab: Proyek di-zip di sistem operasi Windows, di mana shortcut public/storage mengarah ke path Windows. Ketika diekstrak di server Linux cPanel, shortcut tersebut menjadi rusak (*broken link*), sehingga Apache memblokir aksesnya dengan pesan 403 Forbidden.

Solusi 1: Pemulihan Sekali Klik (Rekomendasi)

Cukup buka tautan perbaikan otomatis di browser Anda (tanpa perlu repot membuka terminal/SSH):

https://absensi.maisba.sch.id/fix-storage

Sistem akan otomatis menghapus symlink lama dan membuat symlink Linux yang valid.

Solusi 2: Jika Hosting Mematikan Symlink

Jika paket hosting Anda tidak mengizinkan fungsi symlink:

  1. Buka cPanel → File Manager.
  2. Buka folder public lalu Hapus (Delete) file/shortcut bernama storage.
  3. Selesai! Fitur Fallback Route aplikasi kami akan otomatis mengambil dan menyajikan foto siswa langsung via PHP tanpa perlu symlink.
